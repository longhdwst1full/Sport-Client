# Implement a Storefront feature

Đọc `AGENTS.md`, skill Storefront feature/PWA/API integration và feature spec. Tham khảo `dragon-web-v2` cho foundation, widget composition, skeleton, image, hook và PWA patterns; điều chỉnh theo Next.js App Router hiện tại. Ưu tiên Server Components cho public reads, generated SDK ở boundary phù hợp, đủ responsive/loading/empty/error/offline/update states. Không cache dữ liệu nhạy cảm hoặc mutation thanh toán. Chạy lint, test, generate API khi contract đổi và production build.
