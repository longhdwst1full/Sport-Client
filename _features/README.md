# Storefront feature specifications

Mỗi customer journey có một feature spec: catalog, product detail, cart, checkout hoặc account. Bắt đầu từ `../_templates/feature-spec.template.yml`; chốt rendering boundary, generated API, SEO, responsive/a11y, PWA/offline behavior và commerce safety.

Tham khảo `dragon-web-v2` cho foundation/widget/feature separation và PWA patterns; không copy domain đầu tư, Redux API cache hoặc service-worker policy chưa được đánh giá.
